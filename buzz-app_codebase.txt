# Buzz App

A real-time notification tool for your local network. Open the page on your phone, hit **Buzz Dad** or type a message — it pops up instantly on Dad's computer.

---

## Quick Start (the short version)

**Windows** — just double-click `start.bat`. Done. It handles everything.

**Mac / Linux:**

```bash
node -v          # must be v20.6 or higher — https://nodejs.org if not
npm install      # first time only
npm run dev      # starts the server
```

Then open **http://localhost:3000** in your browser.

To use it from your phone or another device on the same Wi-Fi, use the **Network** address printed in the terminal when the server starts — it looks like `http://192.168.x.x:3000`.

---

## First-Time Setup (step by step)

### 1. Install Node.js (if you haven't already)

Go to **https://nodejs.org** and download the **LTS** version. Run the installer and click through — defaults are fine.

To check it worked, open a terminal and run:

```
node -v
```

You should see something like `v22.x.x`. You need **v20.6 or higher**.

### 2. Get the app running

**Windows** — double-click `start.bat` in the project folder. It will:
- Check your Node.js version
- Install dependencies automatically on first run
- Start the server

**Mac** — open Terminal, navigate to the project folder, then:

```bash
npm install     # only needed once
npm run dev
```

**Linux** — same as Mac.

### 3. Open the app

Once the server is running, your terminal will show something like:

```
  ──────────────────────────────────────────────
   Buzz App
  ──────────────────────────────────────────────
   Local    →  http://localhost:3000
   Network  →  http://192.168.1.42:3000   <- phone / other devices
  ──────────────────────────────────────────────
   Press Ctrl+C to stop
  ──────────────────────────────────────────────
```

- Open the **Local** address on the computer running the server.
- Open the **Network** address on your phone or any other device on the same Wi-Fi.

### 4. Using the app

| What you want to do | How |
|---------------------|-----|
| Get Dad's attention | Click **Buzz Dad** |
| Send a message | Type in the box, then click **Send Message** or press **Enter** |
| See what happened | Check the **Event Log** at the bottom of the page |
| Clear the log | Click **Clear** |

The colored dot in the top-right corner shows your connection status:
- **Green** — connected and ready
- **Yellow (pulsing)** — reconnecting
- **Red** — disconnected (is the server still running?)

### 5. Stopping the server

Press **Ctrl+C** in the terminal window. The server will shut down cleanly.

---

## Troubleshooting

**"node is not recognized" / "command not found"**
Node.js is not installed or not on your PATH. Download it from https://nodejs.org and re-open your terminal after installing.

**Phone can't reach the Network address**
Both devices must be on the same Wi-Fi network. Check that your firewall isn't blocking port 3000.

**Port 3000 is already in use**
Edit `.env` (created automatically on first run) and change `PORT=3000` to any free port, e.g. `PORT=3001`.

**The server stopped unexpectedly**
Read the error output in the terminal — it will tell you what went wrong. Common cause: invalid `.env` values. Delete `.env` to regenerate it from defaults.

---

## Configuration

On first run, a `.env` file is created automatically from `.env.example`. You can edit it any time:

| Variable | Default | What it does |

| `NODE_ENV` | `development` | Runtime environment |
| `LOG_LEVEL` | `info` | Log verbosity (`debug` for more detail) |
| `CORS_ORIGIN` | `*` | Restrict to a specific origin for production use |

setlocal enabledelayedexpansion
title Buzz App

echo.
echo  ============================================================
echo    Buzz App
echo  ============================================================
echo.

:: ── Step 1: Verify Node.js is installed ──────────────────────────────────────
where node >nul 2>nul
if !ERRORLEVEL! neq 0 (
    echo  [ERROR] Node.js is not installed.
    echo.
    echo  Please download and install it from:
    echo  https://nodejs.org  (choose the LTS version^)
    echo.
    echo  After installing, close and re-open this file.
    echo.
    pause
    exit /b 1
)

:: ── Step 2: Verify Node.js version is 20.6 or higher ─────────────────────────
node -e "const [maj,min]=process.versions.node.split('.').map(Number); if(maj<20||(maj===20&&min<6)){console.error('  [ERROR] Node.js 20.6 or higher is required.'); console.error('  You have: '+process.version); console.error('  Download: https://nodejs.org'); process.exit(1);}" 2>&1
if !ERRORLEVEL! neq 0 (
    echo.
    pause
    exit /b 1
)

for /f "delims=" %%v in ('node --version') do set NODE_VER=%%v
echo  Node.js  %NODE_VER%  OK
echo.

:: ── Step 3: Install dependencies on first run ─────────────────────────────────
if not exist "node_modules\" (
    echo  First launch detected — installing dependencies.
    echo  This only happens once and may take a minute...
    echo.
    call npm install
    if !ERRORLEVEL! neq 0 (
        echo.
        echo  [ERROR] npm install failed.
        echo  Check your internet connection and try again.
        echo.
        pause
        exit /b 1
    )
    echo.
    echo  Dependencies installed successfully.
    echo.
)

:: ── Step 4: Run preflight (creates .env from .env.example + prints banner) ────
node scripts/preflight.js
if !ERRORLEVEL! neq 0 (
    echo.
    echo  [ERROR] Preflight failed. See output above.
    echo.
    pause
    exit /b 1
)

:: ── Step 5: Launch directly via node — no wrappers ──────────────────────────
::
::  Why not `npm run dev` or `node --watch`?
::  Both spawn the real server as a CHILD process. On Windows, when the user
::  presses Ctrl+C the parent (npm or the --watch watcher) calls
::  TerminateProcess() on the child before the SIGINT handler has time to emit
::  the server-shutdown broadcast to connected clients (~300 ms window needed).
::
::  Running node src/server.js directly makes the server the immediate child
::  of cmd.exe. Ctrl+C sends CTRL_C_EVENT straight to node.exe, which Node
::  converts to SIGINT and delivers to our process.on('SIGINT') handler.
::
::  Note: dotenv is already imported inside src/config/index.js so --env-file
::  is not needed here.
::
echo  Launching server...
echo.
node src/server.js

:: ── Step 6: Keep the window open so the user can read any error output ────────
echo.
if !ERRORLEVEL! neq 0 (
    echo  [ERROR] The server stopped unexpectedly. See output above.
) else (
    echo  Server stopped.
)
echo.
pause

# Matrix Shutdown Experience — Design & Development Plan

## Overview

`index.html` and `public/matrix.js`
module deliver the full experience. The shutdown is a 6-phase orchestrated sequence that
surgically transforms the living UI into a Matrix terminal.

---

## Phase Diagram (absolute timing from `server-shutdown` event)

```
T+0ms    ─── server-shutdown received ─────────────────────────────────────
T+0       Phase 1: INFILTRATION — rain begins; app UI desaturates/fades
T+2500    Phase 2: TAKEOVER — canvas fully opaque; UI gone; rain at full density
T+3200    Phase 3: MESSAGE 1 — "CONNECTION LOST" ripples in, holds, falls
T+7800    Phase 4: MESSAGE 2 — "SERVER SHUTTING DOWN...." ripples in, holds, falls
T+12400   Phase 5: MESSAGE 3 — "THE SERVER HAS GONE OFFLINE." ripples in, HOLDS
T+∞       Phase 6: IDLE — final message micro-ripples; rain runs forever
```

---

## Part 1 — The Matrix Rain Engine

### 1.1 Canvas Architecture

Two stacked `<canvas>` elements, both `position: fixed; inset: 0; pointer-events: none`:

```
z-index 1000  →  #matrix-rain-canvas   (background rain)
z-index 1001  →  #matrix-msg-canvas    (message glyphs — separate so rain
                                         never draws over the active message)
```

The rain canvas uses the **semi-transparent fill technique**: instead of `clearRect()` each
frame, a `rgba(0,0,0,0.05)` rect is painted over the entire surface. This causes older glyphs
to decay at roughly 1/20th opacity per frame — at 60 fps a character fully fades in ~1.2
seconds. This is the exact mechanism that produces the luminous trailing streams of the source
image.

### 1.2 Character Set

Four pools, weighted by probability:

| Pool | Characters | Draw weight |
|---|---|---|
| Half-width Katakana | `ｦｧｨｩｪｫｬｭｮｯｰｱｲｳｴｵｶｷｸｹｺｻｼｽｾｿﾀﾁﾂﾃﾄﾅﾆﾇﾈﾉﾊﾋﾌﾍﾎﾏﾐﾑﾒﾓﾔﾕﾖﾗﾘﾙﾚﾛﾜﾝ` | 50% |
| Latin uppercase | `A-Z` | 20% |
| Digits | `0-9` | 20% |
| Symbols | `@#$%&*!?<>/\|[]{}` | 10% |

Katakana dominates for authenticity. All pools are concatenated into a single `ALL_CHARS`
string; selection is `ALL_CHARS[Math.floor(Math.random() * ALL_CHARS.length)]`.

### 1.3 Stream (Column) Data Model

Each column maintains an independent state object:

```javascript
{
  x:              number,   // pixel X of left edge of this column
  headY:          number,   // Y pixel of the leading (head) glyph
  speed:          number,   // pixels per frame — 0.8 to 3.0
  streamLen:      number,   // number of glyphs in this stream — 8 to 30
  chars:          string[], // per-slot current glyph character
  mutateInterval: number,   // frames between character mutations — 2 to 6
  mutateTimer:    number,   // counts up to mutateInterval
  glowIntensity:  number,   // 0.6 to 1.0 — varies stream brightness
  active:         boolean,  // false = column paused (message zone exclusion)
}
```

Column width equals font size (14px), giving ~100 columns on a 1440px display.

### 1.4 Per-Frame Draw Call

Every `requestAnimationFrame` tick:

```
1. ctx.fillStyle = 'rgba(0, 0, 0, 0.05)'
   ctx.fillRect(0, 0, W, H)                     ← decay all prior glyphs

2. ctx.font = 'bold 14px "Share Tech Mono", "Courier New", monospace'
   ctx.textBaseline = 'top'

3. For each active column:
   a. Mutate timer: if due, replace 1–3 random char slots with randChar()
   b. For j = 0 to streamLen-1:
        charY = col.headY - j * fontSize
        if charY+fontSize < 0 or charY > H → skip

        t = j / streamLen  (0.0 = head, 1.0 = tail)

        if j === 0:
          ctx.shadowBlur = 15
          ctx.shadowColor = '#00ff41'
          ctx.fillStyle   = 'rgb(230, 255, 230)'   ← near-white head
        else if j < 4:
          ctx.shadowBlur = 8
          ctx.shadowColor = '#00ff41'
          green = lerp(255, 160, t)
          ctx.fillStyle = `rgba(0, ${green}, 20, ${1 - t*0.2})`
        else:
          ctx.shadowBlur = 0
          green = lerp(160, 40, (t-0.3)/0.7)
          alpha = lerp(0.85, 0.08, t)
          ctx.fillStyle = `rgba(0, ${green}, 10, ${alpha})`

        ctx.fillText(col.chars[j], col.x, charY)

   c. col.headY += col.speed * dt    (dt = deltaMs / 16.67 for frame-rate independence)
   d. if col.headY - col.streamLen * fontSize > H:
        reset col (new random speed, length, headY starts above screen)

4. ctx.shadowBlur = 0
```

`lerp(a, b, t)` = `a + (b - a) * clamp(t, 0, 1)`

### 1.5 Visual Fidelity Details

- **Multiple glow radii**: Leading glyphs get `shadowBlur: 15`. Every ~50 frames a random
  column gets a `glowIntensity` spike — character size +2px, shadowBlur +8px — for 3 frames,
  simulating the larger bright characters in the source image.

- **Variable stream density**: Short streams (8–12) at 20% frequency, medium (13–20) at 50%,
  long (21–30) at 30%.

- **Staggered launch**: On `init()` each column gets a random `headY` between
  `-canvas.height * 1.5` and `+canvas.height * 0.5` so the effect looks full immediately.

- **Frame-rate independence**: `speed` is calibrated for 60 fps. The draw loop measures
  `deltaTime` and scales: `col.headY += col.speed * (deltaMs / 16.67)`.

## Part 2 — Infiltration Transition (Phase 1)

### 2.1 The App Fade-Out

When `server-shutdown` fires:

1. Rain canvas starts at `opacity: 0`
2. CSS transitions on `.app`:

```
T+0ms    filter: saturate(1) brightness(1)       → transition begins
T+800ms  filter: saturate(0.15) brightness(0.6) hue-rotate(100deg)
T+1600ms filter: saturate(0) brightness(0.05) hue-rotate(120deg)
T+2000ms opacity: 0

transition: filter 1.6s ease-in, opacity 0.8s 1.6s ease-out
```

3. Rain canvas fades in on the same timeline:

```
T+0     opacity: 0
T+2000  opacity: 1
transition: opacity 2s ease-in
```

The overlap period (T+800 to T+2000) is where both are partially visible — the normal UI
looks like it is being corrupted as green characters bleed through it.

### 2.2 The Body Background Shift

`<body>` background animates from current dark theme to `#000000` over 2500ms, ensuring no
residual dark-blue persists behind the rain.

```css
body.matrix-transition {
  transition: background-color 2.5s ease-in;
  background-color: #000000 !important;
  background-image: none !important;
}
```

## Part 3 — Message Canvas Architecture

### 3.1 Why a Separate Canvas for Messages

The rain canvas uses the `rgba(0,0,0,0.05)` decay trick, which means anything drawn on it
will fade. The message glyphs need to hold sharp and bright. A second canvas
(`#matrix-msg-canvas`) uses `clearRect()` each frame so characters never decay.

### 3.2 `MessageChar` Data Model

```javascript
{
  finalChar:    string,   // the character this slot resolves to
  currentChar:  string,   // what is currently displayed (glitching)
  x:            number,   // final resting X pixel
  y:            number,   // final resting Y pixel (vertically centered)
  currentY:     number,   // current draw Y (animated during fall)
  alpha:        number,   // 0–1
  state:        'hidden' | 'assembling' | 'settled' | 'falling' | 'dead',
  glitchTick:   number,   // countdown to next character mutation
  glitchRate:   number,   // frames between mutations while assembling
  velY:         number,   // downward velocity during fall phase
  velYAccel:    number,   // gravity acceleration
  brightness:   number,   // 1.0 normally; spikes to 2.0 on lock-in flash
  phaseOffset:  number,   // random radians — drives the sinusoidal glow pulse
  microGlitch:  boolean,  // true for Phase 5 held characters
}
```

## Part 4 — Horizontal Ripple Assembly

### 4.1 The Visual Effect

Characters materialize outward from the center of the word in expanding rings.

For `"CONNECTION LOST"` (15 characters, center index 7):

```
Ring 0 delay   0ms: char[7]           ← CENTER appears first
Ring 1 delay  60ms: char[6], char[8]
Ring 2 delay 120ms: char[5], char[9]
Ring 3 delay 180ms: char[4], char[10]
Ring 4 delay 240ms: char[3], char[11]
Ring 5 delay 300ms: char[2], char[12]
Ring 6 delay 360ms: char[1], char[13]
Ring 7 delay 420ms: char[0], char[14] ← outermost, last to appear
```

### 4.2 Per-Character Glitch-In Sequence

```
Frames  1–14:  currentChar = randChar(), alpha = 0.6
               New random glyph each frame — character "hunts" for its target
Frames 15–18:  brightness ramps 1.0 → 2.5 (bright white flash)
               currentChar = finalChar
               color: rgb(200,255,200) → rgb(255,255,255)
Frames 19–22:  brightness ramps 2.5 → 1.2
               color: #ffffff → #40ff80 → #00ff41
Frame  23+:    state = 'settled', brightness = 1.0, color = #00ff41
```

Total glitch-in duration per character: ~380ms at 60 fps.

### 4.3 Text Layout Calculation

```javascript
function computeLayout(text, canvas) {
  const fontSize    = Math.min(56, Math.max(24, canvas.width * 0.04));
  const charWidth   = fontSize * 0.6;
  const letterGap   = fontSize * 0.15;
  const totalWidth  = text.length * charWidth + (text.length - 1) * letterGap;
  const startX      = (canvas.width  - totalWidth) / 2;
  const centerY     = canvas.height / 2;

  return [...text].map((char, i) => ({
    finalChar: char,
    x: startX + i * (charWidth + letterGap),
    y: centerY,
    fontSize,
  }));
}
```

## Part 5 — Character Fall Animation

### 5.1 Fall Trajectory

```
Initial velocity:  velY = 0.5 px/frame
Gravity:           velYAccel = 0.4 px/frame²
Terminal velocity: 35 px/frame

Each frame:
  velY       = min(velY + velYAccel, 35)
  currentY  += velY
  alpha       = max(0, 1 - (currentY - startY) / (canvas.height * 0.7))
```

Alpha fade is distance-based — a character that has fallen 70% of screen height is fully
transparent, creating a natural light-streak without a separate trail object.

### 5.2 Fall Order

Characters fall in **center-outward order** (mirror of ripple-in), with 60ms stagger between
rings. This creates a "collapsing inward" visual.

### 5.3 Mid-Fall Glitch

`glitchRate` increases from its settled value to 2 frames while falling. Characters visibly
scramble as they drop, reinforcing the "losing signal" sensation.

---

## Part 6 — Phase 5: Permanent Micro-Ripple

### 6.1 Settled Final Message

`"THE SERVER HAS GONE OFFLINE."` assembles via the same ripple-in and never falls.
Each character enters `microGlitch` mode:

- Independent `microGlitchTimer` per character, period 90–240 frames (~1.5s–4s)
- On fire: `currentChar` = `randChar()` for exactly **2 frames** (33ms); `brightness` spikes
  to 1.8; then reverts to `finalChar`
- Timers are randomly staggered on init so characters do not glitch simultaneously

### 6.2 Glow Pulse

`shadowBlur` pulses sinusoidally per character with a random `phaseOffset`:

```javascript
shadowBlur = 6 + 4 * Math.sin(frame * 0.04 + char.phaseOffset)
// range: 2–10px   period: ~157 frames (~2.6s at 60 fps)
```

Each character breathes independently — low-level luminescence that slowly waxes and wanes.

## Part 12 — Edge Cases

| Scenario | Handling |
|---|---|
| `server-shutdown` fires while sequence is in progress | `if (this.phase !== 'idle') return` — ignore duplicate events |
| Window resized mid-sequence | `MatrixRain._resize()` reinits columns; message canvas recalculates layout and re-centers all active characters |
| Very narrow viewport (<320px) | `computeLayout()` clamps `fontSize` to 14px minimum; long messages split at spaces onto two lines |
| Canvas `getContext('2d')` returns null | Falls through immediately to `showStaticFallback()` |
| In-browser testing without killing server | `GlitchSequencer` registers `window.__matrixTest = () => sequencer.trigger('Test shutdown')` in development mode |
| `server-shutdown` arrives before DOM is ready | Listener is registered inside `DOMContentLoaded` — not possible in practice since Socket.IO connects after DOM load |

const socket = io({ reconnectionDelayMax: 10_000 });

// --- DOM refs ---
const connDot   = document.getElementById('conn-dot');
const connLabel = document.getElementById('conn-label');
const msgInput  = document.getElementById('msg-input');
const btnBuzz   = document.getElementById('btn-buzz');

// --- Matrix sequencer ---
const sequencer = new GlitchSequencer(
  document.getElementById('matrix-rain-canvas'),
  document.getElementById('matrix-msg-canvas'),
  document.getElementById('matrix-a11y'),
);

// Debug hook — always registered on window.
// Bypasses prefers-reduced-motion so the full animation is visible regardless
// of OS accessibility settings. Works from any hostname (localhost, LAN IP, etc).
// Usage: window.__matrixTest()  or  window.__matrixTest('custom message')
window.__matrixTest = (msg) => sequencer.trigger(msg ?? 'Test shutdown message.', { forceAnimation: true });

// --- Connection lifecycle ---
socket.on('connect', () => {
  setConnState('connected', 'Connected');
  setButtons(true);
  addLog('system', 'Connected to server');
  msgInput.focus();
});

socket.on('disconnect', (reason) => {
  setConnState('disconnected', 'Disconnected');
  setButtons(false);
  addLog('system', `Disconnected: ${reason}`);
});

socket.on('connect_error', () => {
  setConnState('connecting', 'Reconnecting...');
  setButtons(false);
});

// --- Server acknowledgements ---
socket.on('ack', ({ type, message }) => {
  addLog(type === 'error' ? 'error' : 'server', message);
});

// --- Button actions ---
btnBuzz.addEventListener('click', () => {
  socket.emit('buzz-dad');
  addLog('client', 'Buzz Dad sent');
});

btnSend.addEventListener('click', sendMessage);
msgInput.addEventListener('keydown', (e) => {
  if (e.key === 'Enter') sendMessage();
});

btnClear.addEventListener('click', () => {
  logList.innerHTML = '';
  logList.appendChild(logEmpty);
  logEmpty.style.display = '';
});

function sendMessage() {
  const text = msgInput.value.trim();
  if (!text) return;
  socket.emit('send-message', { text });
  addLog('client', `You: "${text}"`);
  msgInput.value = '';
  msgInput.focus();
}

// --- Helpers ---
function setConnState(state, label) {
  connDot.className = `conn-dot ${state}`;
  connLabel.textContent = label;
}

function setButtons(enabled) {
  btnBuzz.disabled = !enabled;
  btnSend.disabled = !enabled;
}

// --- Server shutdown — Matrix takeover ---
socket.on('server-shutdown', ({ message }) => {
  // Remove all socket listeners to prevent reconnect side-effects (audit #43)
  socket.off('connect');
  socket.off('disconnect');
  socket.off('connect_error');
  socket.off('ack');
  socket.disconnect();

  // Also make #matrix-scene scanlines visible
  document.getElementById('matrix-scene').classList.add('active');

  sequencer.trigger(message ?? 'Server is shutting down.');
});

// ─────────────────────────────────────────────────────────────────────────────

// Whitelist of valid log types.  Building a class name from an unvalidated
// server-supplied string would allow a compromised server to inject arbitrary
// CSS classes into the DOM (e.g. to override styling or trigger CSS selector
// attacks in future content-security-policy-free contexts).
const VALID_LOG_TYPES = new Set(['client', 'server', 'error', 'system']);

function addLog(type, text) {
  logEmpty.style.display = 'none';

  const safeType = VALID_LOG_TYPES.has(type) ? type : 'system';
  const item = document.createElement('li');
  item.className = `log-item log-${safeType}`;

  const time = document.createElement('span');
  time.className = 'log-time';
  time.textContent = new Date().toLocaleTimeString();

  const msg = document.createElement('span');
  msg.className = 'log-text';
  msg.textContent = text; // textContent — no innerHTML, no XSS

  item.append(time, msg);
  logList.prepend(item);

  // Cap log at 100 visible entries
  while (logList.children.length > 101) {
    logList.removeChild(logList.lastChild);
  }
}

 * Exports:
 *   class MatrixRain      — canvas rain engine
 *   class GlitchSequencer — orchestrates the full 6-phase shutdown sequence
 *   function randChar()   — returns one random Matrix character

// ─── Character pools ─────────────────────────────────────────────────────────

const KATAKANA = 'ｦｧｨｩｪｫｬｭｮｯｰｱｲｳｴｵｶｷｸｹｺｻｼｽｾｿﾀﾁﾂﾃﾄﾅﾆﾇﾈﾉﾊﾋﾌﾍﾎﾏﾐﾑﾒﾓﾔﾕﾖﾗﾘﾙﾚﾛﾜﾝ';
const LATIN   = 'ABCDEFGHIJKLMNOPQRSTUVWXYZ';
const DIGITS  = '0123456789';
const SYMBOLS = '@#$%&*!?<>/\\|[]{}';

// Two-step weighted selection gives exact 50/20/20/10 distribution regardless
// of pool sizes — flat-string uniform draw would give wrong weights (audit #3).
export function randChar() {
  const r = Math.random();
  if (r < 0.50) return KATAKANA[Math.floor(Math.random() * KATAKANA.length)];
  if (r < 0.70) return LATIN[Math.floor(Math.random() * LATIN.length)];
  if (r < 0.90) return DIGITS[Math.floor(Math.random() * DIGITS.length)];
  return SYMBOLS[Math.floor(Math.random() * SYMBOLS.length)];
}

// ─── Utilities ────────────────────────────────────────────────────────────────

function lerp(a, b, t) {
  return a + (b - a) * Math.max(0, Math.min(1, t));
}

const sleep = ms => new Promise(resolve => setTimeout(resolve, ms));

function prefersReducedMotion() {
  return window.matchMedia('(prefers-reduced-motion: reduce)').matches;
}

// ─── MatrixRain ───────────────────────────────────────────────────────────────

const FONT_SIZE = 13; // CSS pixels — 13px gives ~8% more columns than 14px

export class MatrixRain {
  constructor(canvas) {
    this._canvas    = canvas;
    // alpha:false — opaque raster; faster compositing since background is always black (audit #42)
    this._ctx       = canvas.getContext('2d', { alpha: false });
    this._cols      = [];
    this._rafId     = null;
    this._lastTs    = 0;
    this._colStride = FONT_SIZE;
    this._W         = 0;
    this._H         = 0;
    this._dpr       = 1;
    this._running   = false;
    this._msgZone   = null;   // active message bounds for glow-boost interaction
    this._spikeNext = 50;     // frames until next random glow spike
    this._frame     = 0;
    this._baseFont  = `${FONT_SIZE}px "Share Tech Mono", "Courier New", monospace`;
  }

  async start() {
    // Gate on font availability — silent fallback if font load fails (audit #36)
    try { await document.fonts.load(this._baseFont); } catch (_) { /* use fallback */ }
    this._resize();
    window.addEventListener('resize', () => this._resize());
    // Pre-warm: 60 simulated frames so streams have realistic decay trails
    // before the canvas becomes visible (audit #15, #17)
    this._prewarm(60);
  }

  startLoop() {
    if (this._running) return;
    this._running = true;
    this._lastTs  = performance.now();
    this._rafId   = requestAnimationFrame(ts => this._tick(ts));
  }

  stop() {
    this._running = false;
    if (this._rafId) { cancelAnimationFrame(this._rafId); this._rafId = null; }
  }

  // Register the active message zone so rain heads glow as they pass through it.
  // Rain is never paused — it always flows behind the message canvas (z-index 1001).
  setMessageZone(x1, x2, centerY) {
    this._msgZone = { x1, x2, centerY };
  }

  clearMessageZone() {
    this._msgZone = null;
  }

  // ── Private ────────────────────────────────────────────────────────────────

  _resize() {
    const firstInit = this._cols.length === 0;
    const dpr = window.devicePixelRatio || 1;
    const W   = window.innerWidth;
    const H   = window.innerHeight;
    this._dpr = dpr;
    this._W   = W;
    this._H   = H;

    // Apply DPR to canvas raster; keep CSS dimensions at logical size (audit #1, #2)
    this._canvas.width        = Math.round(W * dpr);
    this._canvas.height       = Math.round(H * dpr);
    this._canvas.style.width  = W + 'px';
    this._canvas.style.height = H + 'px';
    const ctx = this._ctx;
    ctx.setTransform(dpr, 0, 0, dpr, 0, 0);

    // measureText returns CSS-pixel values — safe to call after DPR transform (audit #6, #27)
    ctx.font        = this._baseFont;
    ctx.textBaseline = 'top';
    this._colStride = Math.max(8, Math.ceil(ctx.measureText('ｦ').width));

    if (firstInit) {
      // First call only: build all columns fresh
      this._initCols(W, H);
      return;
    }

    // Subsequent resize (alt-tab, fullscreen, window resize): PRESERVE existing column
    // state so the rain never restarts from scratch. Only add/trim as needed.
    const needed = Math.ceil(W / this._colStride) + 2;
    for (let i = 0; i < this._cols.length; i++) {
      this._cols[i].x = i * this._colStride; // re-anchor x in case stride changed
    }
    while (this._cols.length < needed) {
      this._cols.push(this._makeCol(this._cols.length * this._colStride, H, false));
    }
    if (this._cols.length > needed) this._cols.length = needed;
  }

  _initCols(W, H) {
    const stride  = this._colStride;
    const numCols = Math.ceil(W / stride) + 2;
    this._cols    = [];
    for (let i = 0; i < numCols; i++) {
      this._cols.push(this._makeCol(i * stride, H, true));
    }
  }

  _makeCol(x, H, staggered) {
    const streamLen = this._randStreamLen(H);
    return {
      x,
      // Staggered: spread headY within [0, H] so the screen fills immediately
      // (no above-screen gap period — that was causing empty columns at startup)
      headY:          staggered ? Math.random() * H : 0,
      speed:          0.8 + Math.random() * 2.2,
      streamLen,
      chars:          Array.from({ length: streamLen }, () => randChar()),
      mutateInterval: 2 + Math.floor(Math.random() * 5),
      mutateTimer:    0,
      glowIntensity:  0.6 + Math.random() * 0.4,
      glowSpikeTimer: 0,
    };
  }

  _randStreamLen(H) {
    // Streams must be at least full-screen height so every column cell is
    // always filled — short streams left 70–90% of each column black.
    const screenRows = Math.ceil((H || this._H || 900) / FONT_SIZE);
    // Small variation (0–20 extra rows) so adjacent columns have slightly
    // different tail positions, avoiding a uniform horizontal cutoff line.
    return screenRows + 2 + Math.floor(Math.random() * 20);
  }

  _prewarm(frames) {
    const ctx    = this._ctx;
    const W      = this._W;
    const H      = this._H;
    const stride = this._colStride;
    ctx.font        = this._baseFont;
    ctx.textBaseline = 'top';
    for (let f = 0; f < frames; f++) {
      ctx.fillStyle = 'rgba(0, 0, 0, 0.05)';
      ctx.fillRect(0, 0, W, H);
      for (const col of this._cols) {
        this._drawCol(ctx, col, H, 1.0);
        col.headY += col.speed;
        col.mutateTimer++;
        if (col.mutateTimer >= col.mutateInterval) { this._mutateCol(col); col.mutateTimer = 0; }
        // Reset when HEAD exits screen bottom — not when tail exits.
        // Old condition (tail exits) left the column dark for seconds between passes.
        if (col.headY > H + FONT_SIZE * 4) this._resetCol(col, H);
      }
      ctx.shadowBlur  = 0;
      ctx.shadowColor = 'transparent';
    }
  }

  _tick(ts) {
    if (!this._running) return;
    const elapsed = ts - this._lastTs;
    this._lastTs  = ts;
    // Cap dt at 3× to prevent teleportation after tab switch (audit #13)
    const dt = Math.min(elapsed / 16.67, 3.0);

    const ctx = this._ctx;
    const W   = this._W;
    const H   = this._H;
    this._frame++;

    // Decay rect — scaled by dt so trail length is frame-rate independent (audit #10)
    ctx.fillStyle = `rgba(0, 0, 0, ${Math.min(0.15, 0.05 * dt)})`;
    ctx.fillRect(0, 0, W, H);
    ctx.font        = this._baseFont;
    ctx.textBaseline = 'top';

    // Random glow spike every ~50 frames (audit #7, #14)
    this._spikeNext -= dt;
    if (this._spikeNext <= 0) {
      this._spikeNext = 40 + Math.random() * 20;
      const ci = Math.floor(Math.random() * this._cols.length);
      if (this._cols[ci]) { this._cols[ci].glowSpikeTimer = 3; this._cols[ci].glowIntensity = 1.4; }
    }

    for (const col of this._cols) {
      // Glow spike countdown (audit #7)
      if (col.glowSpikeTimer > 0) {
        col.glowSpikeTimer--;
        if (col.glowSpikeTimer === 0) col.glowIntensity = 0.6 + Math.random() * 0.4;
      }

      this._drawCol(ctx, col, H, dt);
      col.headY       += col.speed * dt;
      col.mutateTimer += dt;
      if (col.mutateTimer >= col.mutateInterval) { this._mutateCol(col); col.mutateTimer = 0; }
      if (col.headY - col.streamLen * FONT_SIZE > H) this._resetCol(col, H);
    }
    ctx.shadowBlur  = 0;
    ctx.shadowColor = 'transparent';

    this._rafId = requestAnimationFrame(ts => this._tick(ts));
  }

  _drawCol(ctx, col, H, dt) {
    const spiking = col.glowSpikeTimer > 0;
    for (let j = 0; j < col.streamLen; j++) {
      const charY = col.headY - j * FONT_SIZE;
      if (charY + FONT_SIZE < 0 || charY > H) continue;

      const t          = j / col.streamLen;           // 0=head, 1=tail
      // Minimum brightness 0.05 at tail keeps every cell faintly visible —
      // prevents hard black cutoff at stream tail (reference image has no empty cells).
      const brightness = Math.max(0.05, 1 - t);
      const green      = Math.floor(lerp(30, 255, brightness));
      const alpha      = lerp(0.10, 0.92, brightness);

      if (j === 0) {
        // Light-interaction: when head passes through the message zone, boost glow
        // so rain visibly "interacts" with the message text rather than ignoring it.
        let effectiveGlow = col.glowIntensity;
        if (this._msgZone) {
          const mz = this._msgZone;
          if (col.x >= mz.x1 - this._colStride * 3 && col.x <= mz.x2 + this._colStride * 3) {
            const dist = Math.abs(charY - mz.centerY);
            if (dist < 80) {
              effectiveGlow = Math.min(2.0, effectiveGlow + (1 - dist / 80) * 1.2);
            }
          }
        }
        // Head — glow only on leading char, keeps shadow call count low (audit #9)
        ctx.shadowBlur  = (spiking ? 22 : 15) * effectiveGlow;
        ctx.shadowColor = '#00ff41';
        ctx.fillStyle   = (spiking || effectiveGlow > 1.2) ? 'rgb(255,255,255)' : 'rgb(230,255,230)';
      } else {
        ctx.shadowBlur = 0;  // reset each char so no bleed to next column (audit #11)
        ctx.fillStyle  = `rgba(0,${green},${Math.floor(green * 0.08)},${alpha.toFixed(2)})`;
      }
      ctx.fillText(col.chars[j], col.x, charY);
    }
    // Explicit reset after every column (audit #11)
    ctx.shadowBlur  = 0;
    ctx.shadowColor = 'transparent';
  }

  _mutateCol(col) {
    const count = 1 + Math.floor(Math.random() * 3);
    for (let k = 0; k < count; k++) {
      col.chars[Math.floor(Math.random() * col.streamLen)] = randChar();
    }
  }

  _resetCol(col, H) {
    // headY = 0: restart immediately from screen top with no above-screen gap.
    // Old -FONT_SIZE*2 caused the column to be black for the full travel time
    // above the screen before any characters appeared — that was the source of
    // the large dark gaps visible between streams.
    col.headY          = 0;
    col.speed          = 0.8 + Math.random() * 2.2;
    col.streamLen      = this._randStreamLen(H);
    col.chars          = Array.from({ length: col.streamLen }, () => randChar());
    col.glowIntensity  = 0.6 + Math.random() * 0.4;
    col.glowSpikeTimer = 0;
  }
}

// ─── GlitchSequencer ─────────────────────────────────────────────────────────

const MSG1 = 'CONNECTION LOST';
const MSG2 = 'SERVER SHUTTING DOWN....';
const MSG3 = 'THE SERVER HAS GONE OFFLINE.';

export class GlitchSequencer {
  constructor(rainCanvas, msgCanvas, a11yEl) {
    this._rain    = new MatrixRain(rainCanvas);
    this._rCanvas = rainCanvas;
    this._mCanvas = msgCanvas;
    // alpha:true on message canvas — transparent so rain shows through (audit #42)
    this._mCtx    = msgCanvas.getContext('2d');
    this._a11y    = a11yEl;
    this._phase   = 'idle';
    this._chars   = [];
    this._msgFont = null;
    this._msgRaf  = null;
    this._W       = window.innerWidth;
    this._H       = window.innerHeight;
    this._dpr     = window.devicePixelRatio || 1;

    this._setupMsgCanvas();
    window.addEventListener('resize', () => this._setupMsgCanvas());
  }

  // forceAnimation: true bypasses prefers-reduced-motion (used by __matrixTest)
  async trigger(customMessage, { forceAnimation = false } = {}) {
    if (this._phase !== 'idle') return;
    this._phase = 'running';

    if (!forceAnimation && prefersReducedMotion()) {
      this._showStatic(customMessage);
      return;
    }

    // Cancel bgdrift animation before applying matrix transition (audit #18)
    document.body.style.animation = 'none';
    document.body.classList.add('matrix-transition');

    // Corrupt the app UI
    const app = document.querySelector('.app');
    if (app) app.classList.add('matrix-corrupting');

    // Pre-warm rain before it becomes visible, then start RAF loop (audit #15, #17)
    await this._rain.start();
    this._rain.startLoop();

    // Start message canvas draw loop
    this._startMsgLoop();

    // After 500ms, fade both canvases in
    await sleep(500);
    this._rCanvas.classList.add('active');
    this._mCanvas.classList.add('active');

    // Wait for corruption animation + rain fade-in to finish (~2200ms)
    await sleep(2200);

    // Phase 2: density build
    await sleep(600);

    // Phase 3: first message
    await this._showMessage(MSG1, false);
    await sleep(400);

    // Phase 4: second message
    await this._showMessage(MSG2, false);
    await sleep(400);

    // Phase 5: final message — permanent hold with micro-ripple
    await this._showMessage(MSG3, true);
  }

  // ── Message canvas setup ──────────────────────────────────────────────────

  _setupMsgCanvas() {
    const dpr = window.devicePixelRatio || 1;
    const W   = window.innerWidth;
    const H   = window.innerHeight;
    this._dpr = dpr;
    this._W   = W;
    this._H   = H;

    this._mCanvas.width        = Math.round(W * dpr);
    this._mCanvas.height       = Math.round(H * dpr);
    this._mCanvas.style.width  = W + 'px';
    this._mCanvas.style.height = H + 'px';
    const ctx = this._mCtx;
    ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
  }

  _startMsgLoop() {
    const ctx  = this._mCtx;
    const draw = () => {
      ctx.clearRect(0, 0, this._W, this._H);
      const now = performance.now();
      for (const ch of this._chars) this._tickChar(ch, ctx, now);
      ctx.shadowBlur  = 0;
      ctx.shadowColor = 'transparent';
      this._msgRaf = requestAnimationFrame(draw);
    };
    this._msgRaf = requestAnimationFrame(draw);
  }

  // ── Per-character tick ────────────────────────────────────────────────────

  _tickChar(ch, ctx, now) {
    if (ch.state === 'hidden' || ch.state === 'dead') return;
    if (ch.finalChar === ' ') return; // spaces are invisible — skip (audit #20)

    if (ch.state === 'assembling') this._tickAssembling(ch, now);
    if (ch.state === 'falling')    this._tickFalling(ch, now);
    if (ch.state === 'settled' && ch.microGlitch) this._tickMicroGlitch(ch, now);

    const pulseBlur = ch.state === 'settled'
      // Sinusoidal glow pulse using performance.now() — frame-rate independent (audit #31)
      ? 6 + 4 * Math.sin(now * 0.0025 + ch.phaseOffset)
      : 0;

    this._drawGlowChar(ctx, ch.currentChar, ch.x, ch.currentY, ch.fontSize, ch.flashT, ch.alpha, pulseBlur);
  }

  _tickAssembling(ch, now) {
    // Time-based glitch-in — does not compress at high refresh rates (audit #24)
    const elapsed = now - ch.activatedAt;
    if (elapsed < 233) {
      ch.currentChar = randChar();
      ch.flashT      = 0;
      ch.alpha       = 0.6;
    } else if (elapsed < 300) {
      ch.currentChar = ch.finalChar;
      ch.flashT      = (elapsed - 233) / 67;   // 0→1 white ramp
      ch.alpha       = 1.0;
    } else if (elapsed < 370) {
      ch.flashT      = 1 - (elapsed - 300) / 70; // 1→0 back to green
      ch.alpha       = 1.0;
    } else {
      ch.state       = 'settled';
      ch.currentChar = ch.finalChar;
      ch.flashT      = 0;
      ch.alpha       = 1.0;
    }
  }

  _tickFalling(ch, now) {
    const dt = Math.min((now - (ch._lastFallTick || now)) / 16.67, 3.0);
    ch._lastFallTick = now;

    const GRAVITY   = 0.4;
    const TERMINAL  = 35;
    ch.velY         = Math.min(ch.velY + GRAVITY * dt, TERMINAL);
    ch.currentY    += ch.velY * dt;

    // Alpha fades to 0 by the time char exits screen (audit #28)
    const screenH      = this._H;
    const fadeDistance = Math.max(screenH * 0.5, screenH - ch.startY + screenH * 0.15);
    ch.alpha           = Math.max(0, 1 - (ch.currentY - ch.startY) / fadeDistance);

    // Scramble chars during fall
    if (Math.random() < 0.08) ch.currentChar = randChar();

    if (ch.alpha <= 0 || ch.currentY > screenH + 60) ch.state = 'dead';
  }

  _tickMicroGlitch(ch, now) {
    // setTimeout-based revert — duration is in real ms, not frames (audit #32)
    if (now >= ch.microGlitchAt) {
      ch.microGlitchAt    = now + 1500 + Math.random() * 2500;
      const saved         = ch.finalChar;
      ch.currentChar      = randChar();
      ch.flashT           = 0.35;
      setTimeout(() => { ch.currentChar = saved; ch.flashT = 0; }, 33);
    }
  }

  // ── Multi-pass glow renderer (audit #33) ──────────────────────────────────

  _drawGlowChar(ctx, char, x, y, fontSize, flashT, alpha, extraBlur) {
    if (!char || char === ' ') return;
    // Interpolate rgb(0,255,65) → rgb(255,255,255) for lock-in flash (audit #23)
    const r  = Math.round(lerp(0,   255, flashT));
    const g  = 255;
    const b  = Math.round(lerp(65,  255, flashT));
    const a  = Math.max(0, Math.min(1, alpha));
    const eb = extraBlur || 0;

    ctx.font        = `${fontSize}px "Share Tech Mono", "Courier New", monospace`;
    ctx.textBaseline = 'middle'; // vertically centres on y coordinate (audit #25)

    // Pass 1 — wide outer halo
    ctx.shadowBlur  = 48 + eb;
    ctx.shadowColor = `rgba(0,255,65,${(0.22 * a).toFixed(2)})`;
    ctx.fillStyle   = `rgba(0,255,65,${(0.10 * a).toFixed(2)})`;
    ctx.fillText(char, x, y);

    // Pass 2 — mid glow
    ctx.shadowBlur  = 24 + eb * 0.5;
    ctx.shadowColor = `rgba(0,255,65,${(0.45 * a).toFixed(2)})`;
    ctx.fillStyle   = `rgba(0,255,65,${(0.30 * a).toFixed(2)})`;
    ctx.fillText(char, x, y);

    // Pass 3 — inner glow with color interpolated for flash
    ctx.shadowBlur  = 10;
    ctx.shadowColor = `rgba(0,255,65,${a.toFixed(2)})`;
    ctx.fillStyle   = `rgba(${r},${g},${b},${(0.82 * a).toFixed(2)})`;
    ctx.fillText(char, x, y);

    // Pass 4 — sharp opaque fill
    ctx.shadowBlur = 0;
    ctx.fillStyle  = `rgba(${r},${g},${b},${a.toFixed(2)})`;
    ctx.fillText(char, x, y);
  }

  // ── Layout calculation (audit #26, #27) ───────────────────────────────────

  _computeLayout(text) {
    const ctx = this._mCtx;
    const W   = this._W;
    const H   = this._H;

    // Responsive starting font size
    let fontSize = Math.min(56, Math.max(12, Math.round(W * 0.04)));

    // Shrink font until text fits within 92% of viewport width (audit #26)
    let colStride, totalWidth;
    for (let attempt = 0; attempt < 60; attempt++) {
      ctx.font   = `${fontSize}px "Share Tech Mono", "Courier New", monospace`;
      colStride  = ctx.measureText('ｦ').width; // measured advance (audit #27)
      totalWidth = text.length * colStride;
      if (totalWidth <= W * 0.92 || fontSize <= 12) break;
      fontSize--;
    }

    // Still overflows at min size — split into two lines (audit #26)
    if (totalWidth > W * 0.92 && fontSize <= 12) {
      return this._twoLineLayout(text, fontSize, colStride, W, H);
    }

    this._msgFont = `${fontSize}px "Share Tech Mono", "Courier New", monospace`;
    const startX  = (W - totalWidth) / 2;
    const centerY = H / 2;

    return [...text].map((char, i) => this._makeChar(char, startX + i * colStride, centerY, fontSize));
  }

  _twoLineLayout(text, fontSize, colStride, W, H) {
    // Split at last space at or before midpoint
    const mid      = Math.floor(text.length / 2);
    let splitAt    = text.lastIndexOf(' ', mid);
    if (splitAt <= 0) splitAt = text.indexOf(' ');
    if (splitAt <= 0) splitAt = mid; // no space — hard split

    const line1 = text.slice(0, splitAt).trimEnd();
    const line2 = text.slice(splitAt).trimStart();
    const lineH = fontSize * 1.6;

    const makeRow = (str, y) => {
      const tw     = str.length * colStride;
      const startX = (W - tw) / 2;
      return [...str].map((ch, i) => this._makeChar(ch, startX + i * colStride, y, fontSize));
    };

    this._msgFont = `${fontSize}px "Share Tech Mono", "Courier New", monospace`;
    return [
      ...makeRow(line1, H / 2 - lineH * 0.55),
      ...makeRow(line2, H / 2 + lineH * 0.55),
    ];
  }

  _makeChar(finalChar, x, y, fontSize) {
    return {
      finalChar,
      currentChar:    finalChar,
      x,
      y,
      currentY:       y,
      startY:         y,          // captured before fall begins (audit #8)
      alpha:          0,
      state:          'hidden',
      flashT:         0,
      activatedAt:    0,
      velY:           0.5,
      phaseOffset:    Math.random() * Math.PI * 2,
      microGlitch:    false,
      microGlitchAt:  0,
      fontSize,
      _lastFallTick:  0,
    };
  }

  // ── Message orchestration ─────────────────────────────────────────────────

  async _showMessage(text, hold) {
    // Update SR-only live region (audit #19)
    if (this._a11y) this._a11y.textContent = text;

    const chars = this._computeLayout(text);
    this._chars = chars;

    // Register message zone for rain glow-boost interaction.
    // Rain is NEVER paused — it flows behind the message canvas (z-index 1001).
    // Pausing columns created a solid black void in the center of the screen.
    const xs      = chars.filter(c => c.finalChar !== ' ').map(c => c.x);
    const xMin    = Math.min(...xs);
    const xMax    = Math.max(...xs) + (chars[0]?.fontSize || FONT_SIZE);
    const centerY = chars[0]?.y ?? this._H / 2;
    this._rain.setMessageZone(xMin, xMax, centerY);

    // Ripple-in from center outward
    const lines = this._groupLines(chars);
    await this._rippleIn(lines);

    // Wait for last char's glitch-in to complete + settle buffer
    await sleep(370 + 120);
    // Hold
    await sleep(800);

    if (hold) {
      // Enable micro-ripple for all settled chars (Phase 5) (audit #32)
      for (const ch of chars) {
        if (ch.state === 'settled') {
          ch.microGlitch   = true;
          ch.microGlitchAt = performance.now() + 1500 + Math.random() * 2500;
        }
      }
      return; // never falls — zone stays registered forever
    }

    // Fall — edge-inward order (outermost characters fall first) (audit #30)
    await this._triggerFall(lines);

    // Wait for fall to complete, then clear zone and chars
    await sleep(1000);
    this._rain.clearMessageZone();
    this._chars = [];
  }

  _groupLines(chars) {
    // Group chars by their y position (handles both 1-line and 2-line layout)
    const byY = new Map();
    for (const ch of chars) {
      const key = Math.round(ch.y);
      if (!byY.has(key)) byY.set(key, []);
      byY.get(key).push(ch);
    }
    // Sort lines top-to-bottom
    return [...byY.values()].sort((a, b) => a[0].y - b[0].y);
  }

  async _rippleIn(lines) {
    // Fire all lines simultaneously, each with its own center
    let maxRing = 0;
    for (const line of lines) {
      const n      = line.length;
      const center = Math.floor((n - 1) / 2);
      const rings  = Math.max(center, n - 1 - center);
      if (rings > maxRing) maxRing = rings;
    }

    for (let ring = 0; ring <= maxRing; ring++) {
      for (const line of lines) {
        const n      = line.length;
        const center = Math.floor((n - 1) / 2);
        const indices = [];
        if (center - ring >= 0)          indices.push(center - ring);
        if (ring > 0 && center + ring < n) indices.push(center + ring);

        for (const i of indices) {
          const ch = line[i];
          if (ch.finalChar === ' ') {
            ch.state = 'settled'; ch.alpha = 0; // spaces skipped (audit #20)
          } else {
            ch.state       = 'assembling';
            ch.activatedAt = performance.now();
            ch.alpha       = 0.6;
          }
        }
      }
      if (ring < maxRing) await sleep(60);
    }
    return maxRing;
  }

  async _triggerFall(lines) {
    // Edge-inward: outermost ring falls first (audit #30 — "mirror of ripple-in"
    // is clarified to mean edge→center, making the message contract inward)
    let maxRing = 0;
    for (const line of lines) {
      const n = line.length;
      maxRing = Math.max(maxRing, Math.max(Math.floor((n - 1) / 2), n - 1 - Math.floor((n - 1) / 2)));
    }

    for (let ring = maxRing; ring >= 0; ring--) {
      for (const line of lines) {
        const n      = line.length;
        const center = Math.floor((n - 1) / 2);
        const indices = [];
        if (center - ring >= 0)          indices.push(center - ring);
        if (ring > 0 && center + ring < n) indices.push(center + ring);

        for (const i of indices) {
          const ch = line[i];
          if (ch.state === 'settled') {
            ch.state         = 'falling';
            ch.startY        = ch.currentY;
            ch._lastFallTick = performance.now();
            ch.velY          = 0.5;
          }
        }
      }
      if (ring > 0) await sleep(60);
    }
  }

  // ── Reduced motion fallback ───────────────────────────────────────────────

  _showStatic(customMessage) {
    // Cancel bgdrift and snap to black
    document.body.style.animation = 'none';
    document.body.classList.add('matrix-transition');
    const app = document.querySelector('.app');
    if (app) { app.style.opacity = '0'; app.style.pointerEvents = 'none'; }

    this._rCanvas.classList.add('active');
    this._mCanvas.classList.add('active');

    // Draw static text on message canvas
    const ctx = this._mCtx;
    const W   = this._W;
    const H   = this._H;
    ctx.clearRect(0, 0, W, H);
    ctx.font        = '24px "Share Tech Mono", "Courier New", monospace';
    ctx.fillStyle   = '#00ff41';
    ctx.textBaseline = 'middle';
    ctx.textAlign    = 'center';

    const messages = [MSG1, MSG2, MSG3];
    const lineH    = 40;
    const startY   = H / 2 - lineH;
    messages.forEach((m, i) => ctx.fillText(m, W / 2, startY + i * lineH));
    ctx.textAlign = 'left'; // reset

    if (this._a11y) this._a11y.textContent = messages.join('. ');
  }
}

const httpServer = createServer(app);

// --- Socket.IO ---
const io = new Server(httpServer, {
  cors: { origin: config.cors.origin },
  connectionStateRecovery: {
    // Cap how long the server buffers events for a disconnected client.
    // Default is 2 minutes which can consume significant memory under connection churn.
    maxDisconnectionDuration: 30_000, // 30 seconds
    skipMiddlewares: true,
  },
});

// --- Middleware ---
// If running behind a reverse proxy (nginx, Caddy, etc.) uncomment the line
// below so express-rate-limit sees the real client IP instead of the proxy IP.
// app.set('trust proxy', 1);

app.use(helmet({ contentSecurityPolicy: false })); // tighten CSP in production
app.use(cors({ origin: config.cors.origin }));
app.use(express.json({ limit: '10kb' }));
app.use(
  rateLimit({
    windowMs: config.rateLimit.windowMs,
    max: config.rateLimit.max,
    standardHeaders: true,
    legacyHeaders: false,
  })
);

// --- Static & routes ---
app.use(express.static(join(__dirname, '..', 'public')));
app.use('/api', healthRouter);

// --- Socket handlers ---
registerSocketHandlers(io);

// --- Error handler (must be last middleware) ---
app.use(errorHandler);

// --- Graceful shutdown ---
function shutdown(signal) {
  logger.info({ signal }, 'Shutdown signal received, closing server...');

  // Step 1: Warn all connected clients before tearing down anything.
  // broadcastShutdown must fire before disconnectSockets — once sockets are
  // closed the emit packet never reaches clients.
  broadcastShutdown(io);

  // Step 2: Wait ~300 ms so the broadcast packet has time to reach clients
  // over a LAN Wi-Fi link before the transport is torn down.
  setTimeout(() => {
    // Step 3: Close all WebSocket connections.
    // Without this, httpServer.close() waits for keep-alive connections to
    // drain which, for WebSockets, means waiting forever.
    io.disconnectSockets(true);

    httpServer.close(() => {
      logger.info('HTTP server closed');
      process.exit(0);
    });
  }, 300);

  // Force-kill if graceful close stalls
  setTimeout(() => {
    logger.error('Forced shutdown after timeout');
    process.exit(1);
  }, 10_000).unref();
}

process.on('SIGTERM', () => shutdown('SIGTERM'));
process.on('SIGINT', () => shutdown('SIGINT'));

process.on('uncaughtException', (err) => {
  logger.fatal({ err }, 'Uncaught exception');
  process.exit(1);
});

process.on('unhandledRejection', (reason) => {
  logger.fatal({ reason }, 'Unhandled promise rejection');
  process.exit(1);
});

// --- Start ---
httpServer.listen(config.port, () => {
  logger.info({ port: config.port, env: config.nodeEnv }, 'Server started');
});

import { z } from 'zod';
import { logger } from '../lib/logger.js';

// .trim() must come BEFORE .min() so whitespace-only strings ('   ') are
// correctly rejected instead of passing the length check and then becoming ''.
const MessageSchema = z.object({
  text: z.string().trim().min(1, 'Message cannot be empty').max(500, 'Message too long'),
});

// ── Per-socket rate limiters ───────────────────────────────────────────────
// Simple in-memory sliding-window counter per socket.
// Entries are cleaned up on disconnect so there is no unbounded memory growth.

const BUZZ_LIMIT = { windowMs: 10_000, max: 5 };   // 5 buzzes per 10 s
const MSG_LIMIT  = { windowMs: 5_000,  max: 20 };  // 20 messages per 5 s

function makeRateLimiter() {
  // Map<socketId, { count: number, resetAt: number }>
  const store = new Map();
  return {
    isLimited(socketId, { windowMs, max }) {
      const now = Date.now();
      const entry = store.get(socketId);
      if (!entry || now >= entry.resetAt) {
        store.set(socketId, { count: 1, resetAt: now + windowMs });
        return false;
      }
      if (entry.count >= max) return true;
      entry.count++;
      return false;
    },
    remove(socketId) {
      store.delete(socketId);
    },
  };
}

const buzzLimiter = makeRateLimiter();
const msgLimiter  = makeRateLimiter();

// ─────────────────────────────────────────────────────────────────────────────

// Emits a warning to all connected clients before the server tears down
// sockets. Must be called BEFORE io.disconnectSockets() — once sockets are
// closed the emit packet never reaches clients.
export function broadcastShutdown(io) {
  io.emit('server-shutdown', {
    message: 'Server is shutting down. Connection will be lost.',
  });
}

export function registerSocketHandlers(io) {
  io.on('connection', (socket) => {
    logger.info({ socketId: socket.id }, 'Client connected');

    // ── buzz-dad ────────────────────────────────────────────────────────────
    socket.on('buzz-dad', () => {
      if (buzzLimiter.isLimited(socket.id, BUZZ_LIMIT)) {
        logger.warn({ socketId: socket.id }, 'buzz-dad rate limit exceeded');
        socket.emit('ack', { type: 'error', message: 'Slow down — too many buzzes.' });
        return;
      }

      logger.info({ socketId: socket.id }, 'Buzz received');
      // TODO: play audio on server machine — add a package like `play-sound` here
      socket.emit('ack', { type: 'buzz', message: 'Buzz received — Dad has been alerted!' });
    });

    // ── send-message ────────────────────────────────────────────────────────
    socket.on('send-message', (data, callback) => {
      if (msgLimiter.isLimited(socket.id, MSG_LIMIT)) {
        logger.warn({ socketId: socket.id }, 'send-message rate limit exceeded');
        socket.emit('ack', { type: 'error', message: 'Slow down — too many messages.' });
        if (typeof callback === 'function') callback({ ok: false, error: 'Rate limit exceeded' });
        return;
      }

      const result = MessageSchema.safeParse(data);

      if (!result.success) {
        const issue = result.error.issues[0]?.message ?? 'Invalid input';
        // Log only the type of data, never the raw value — prevents log injection
        // and avoids writing arbitrarily large payloads to the log stream.
        logger.warn({ socketId: socket.id, dataType: typeof data }, 'Message validation failed');
        socket.emit('ack', { type: 'error', message: `Validation error: ${issue}` });
        if (typeof callback === 'function') callback({ ok: false, error: issue });
        return;
      }

      const { text } = result.data;
      logger.info({ socketId: socket.id }, 'Message received');
      socket.emit('ack', { type: 'message', message: `Server received: "${text}"` });
      if (typeof callback === 'function') callback({ ok: true });
    });

    // ── lifecycle ───────────────────────────────────────────────────────────
    socket.on('disconnect', (reason) => {
      // Clean up rate-limiter state so memory doesn't grow with connection churn
      buzzLimiter.remove(socket.id);
      msgLimiter.remove(socket.id);
      logger.info({ socketId: socket.id, reason }, 'Client disconnected');
    });

    socket.on('error', (err) => {
      logger.error({ socketId: socket.id, err }, 'Socket error');
    });
  });
}

import { logger } from '../lib/logger.js';
import { config } from '../config/index.js';

/**
 * Centralised Express error handler.
 * Express 5 automatically catches async errors, so any thrown error lands here.
 */
// eslint-disable-next-line no-unused-vars
export function errorHandler(err, req, res, _next) {
  logger.error({ err, path: req.path }, 'Unhandled request error');

  // Sanitize the status code: accept only valid 4xx/5xx integers.
  // An error object with a bogus .status (NaN, 999, -1, a string, …) must
  // fall back to 500 rather than producing a malformed HTTP response.
  const raw = err.status ?? err.statusCode;
  const status =
    Number.isInteger(raw) && raw >= 400 && raw <= 599
      ? raw
      : 500;

  // Never reveal internal error messages for 5xx responses in production.
  // 4xx errors are safe to forward — they describe a client mistake, not a
  // server implementation detail.
  const isServerError = status >= 500;
  const message =
    isServerError && config.nodeEnv === 'production'
      ? 'Internal Server Error'
      : err.message || 'Internal Server Error';

  res.status(status).json({ error: { message } });
}
